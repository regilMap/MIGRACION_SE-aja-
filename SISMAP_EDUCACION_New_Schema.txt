================================================================================
                    NOTAS PARA LA MIGRACIÓN
================================================================================

1. COLUMNAS COMUNES (Auditoría):
   - CreatedAt, CreatedBy, UpdatedAt, UpdatedBy, IsActive, IsDeleted
   - Presentes en casi todas las tablas (patrón de soft delete)

2. TIPOS DE DATOS ESPECIALES:
   - UNIQUEIDENTIFIER: Usado para IDs de usuarios
   - VARBINARY(MAX): Archivos binarios
   - FILESTREAM: Tabla Archivos_SE usa FileStream
   - DECIMAL(18,2): Para valores monetarios/pesos
   - DATETIME2(7): Fechas con alta precisión

3. TABLAS PRINCIPALES (Core):
   - Usuario.Usuarios (usuarios del sistema)
   - Mantenimiento.Indicadores -> SubIndicadores (estructura jerárquica)
   - Evidencia.Evidencias -> SubIndicadorEvidencias -> Archivos
   - Evidencia.RevisionEvidencias -> Puntuacion

4. DEPENDENCIAS EXTERNAS:
   - CoedomId: Referencia a organismos externos (COEDOM/SIGERD)
   - OrganismoID: En tabla SigerdCoedom y vistas

5. FILESTREAM:
   - La tabla Archivos_SE usa FILESTREAM para almacenar archivos
   - Requiere configuración especial en SQL Server
